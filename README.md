# 3D-Editor

Настольный 3D-редактор сцены на **Electron + Three.js**.

## Возможности

- Добавление примитивов: куб, сфера, цилиндр, конус, тор, капсула, узел тора, плоскость.
- Источники света: точечный и направленный (с тенями).
- Выделение объектов кликом, рамка выделения.
- Гизмо перемещения / поворота / масштаба (локальные и мировые оси).
- Аутлайнер сцены: видимость, переименование (двойной клик), удаление.
- Панель свойств: трансформация, материал (цвет, металличность, шероховатость, каркас), параметры света.
- Undo / Redo (снимки сцены).
- Настройки сцены: цвет фона, сетка, оси, тени.
- Сохранение / открытие проекта в JSON.
- Экспорт в **GLB** и скриншот вьюпорта в **PNG**.
- Виды: перспектива, спереди, сверху, сбоку.

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| Клик | Выделить объект |
| `W` / `E` / `R` | Перемещение / Поворот / Масштаб |
| `F` | Фокус на выбранном |
| `Delete` | Удалить объект |
| `Esc` | Снять выделение |
| `Ctrl+N` | Новая сцена |
| `Ctrl+O` | Открыть |
| `Ctrl+S` | Сохранить |
| `Ctrl+E` | Экспорт GLB |
| `Ctrl+Shift+S` | Скриншот |
| `Ctrl+Z` / `Ctrl+Y` | Отменить / Повторить |
| `Ctrl+D` | Дублировать |

## Запуск

```bash
npm install
npm start
```

## Сборка приложения

```bash
npm run dist          # под текущую ОС
npm run dist:linux    # AppImage
npm run dist:win      # NSIS
npm run dist:mac      # DMG
```

Результат в папке `dist/`.

## Структура

```
main.js       — процесс Electron (окно, меню, локальный сервер, диалоги файлов)
preload.js    — безопасный мост IPC (открытие/сохранение файлов)
index.html    — разметка интерфейса
css/style.css — оформление
js/app.js     — движок редактора на Three.js
```
